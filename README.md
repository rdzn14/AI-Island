# 🤖 Mochi Dynamic Island (v0.4)

> **Transform your Android punch-hole into an interactive AI companion, live media controller, and system dashboard!**

---

## ✨ Features

- 🎭 **Interactive Mochi Mascot:** Expression changes based on status (gets dizzy when shaken!).
- 🎵 **Smart Media Controller:** Expanded player with live song info, animated equalizer, and media keys (Prev/Pause/Next).
- 🔔 **Clean Notification Hub:** Takes over system pop-ups for seamless, overlay-free notifications.
- 📊 **Hardware Stats Dashboard:** Monitor Battery (with Temp), RAM, CPU, and GPU stats in real-time.
- 🎛️ **Custom Island Positioning:** Adjust X/Y coordinates to perfectly fit any camera punch-hole layout.
- 🎙️ **Voice Integration:** Ready for seamless AI assistant interactions.

---

## 🛠️ Built With

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material3)
- **Services:** `AccessibilityService` & `NotificationListenerService`
- **Build System:** Gradle (GitHub Actions Cloud Build)

---

## 🚀 Installation & Usage

1. Download the latest `app-debug.apk` from the **Releases** section or Actions build artifact.
2. Install the APK on your Android device.
3. Grant **Accessibility** and **Notification Access** permissions in the app settings.
4. Customize your island offset via the **Setting** tab to align with your camera punch-hole!
